# **Summary**
# Perícias iniciais
Todo personagem pode escolher 4 pertícias iniciais. Além disso, para cada ponto de **Inteligência**, a personagem escolhe **4 perícias**. Cada perícia escolhida recebe **+4 de graduação**.
A personagem também poderá adquirir a vantagem [Avanço de perícias](/p/3f05a119fbdc804197f1de72044290b3) para melhoras suas graduações.
# Limite de graduação
A graduação máxima de uma perícia depende do patamar da personagem:

| Patamar | Graduação máxima |
| --- | --- |
| Sobrevivente | +4 |
| Aventureiro | +8 |
| Campeão | +12 |
| Épico | Sem limite |
